# Valheim Server Manager en AWS

Proyecto final de Introducción a AWS Cloud (UM), de Lucas Gómez y Martín Bentura. Prendemos los servidores de Valheim desde un panel web y se apagan solos cuando no queda nadie jugando.

- `01-red.yaml` a `04-servidor.yaml`: templates de CloudFormation, se despliegan en ese orden.
- `panel/`: panel web.
- `diagramas/`: diagramas de arquitectura, redes, tráfico, seguridad y ciclo de vida.

Detalle completo en el informe.
